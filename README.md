# Healthcare Data Analytics

## Project Overview

This Healthcare Data Analytics project analyzes hospital operations and patient data to generate actionable business insights using SQL, Excel, and Power BI. The project focuses on identifying trends in patient visits, doctor performance, billing, appointments, and departmental efficiency to support data-driven decision-making.

## Objectives

* Analyze patient demographics and visit patterns.
* Evaluate doctor performance based on appointments and revenue.
* Monitor hospital billing and payment status.
* Identify top-performing departments and treatments.
* Build interactive dashboards to visualize key performance indicators (KPIs).

## Tools & Technologies

* **SQL (MySQL):** Data extraction, cleaning, joins, CTEs, window functions, and business queries.
* **Excel:** Data validation, PivotTables, XLOOKUP, charts, and preliminary analysis.
* **Power BI:** Interactive dashboards, DAX measures, KPIs, slicers, and visual storytelling.

## Dataset

The dataset contains information on:

* Patients
* Doctors
* Departments
* Appointments
* Treatments
* Billing and Payments

## Key Analysis Performed

* Monthly patient visit trends
* Department-wise revenue analysis
* Doctor performance ranking
* Most common treatments
* Appointment status analysis
* Payment status tracking
* Top-paying patients
* Revenue by department and doctor

## Key Insights

* Identified departments generating the highest revenue.
* Analyzed patient flow to detect peak appointment periods.
* Ranked doctors based on patient volume and revenue contribution.
* Evaluated billing performance by comparing paid and pending invoices.
* Highlighted treatment trends to support resource planning and operational improvements.

## Outcome

This project demonstrates practical data analytics skills, including data querying, cleaning, visualization, and business insight generation. It showcases the ability to transform raw healthcare data into meaningful reports and dashboards that support informed decision-making.
